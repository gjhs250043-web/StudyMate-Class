StudyMate Class v6 - 배포 준비 버전

학생 계정
- 최성국 / 1234
- 이현찬 / 1234
- 정혁 / 1234
- 한태웅 / 1234

선생님 계정
- 이수빈 / 1234

[내 컴퓨터에서 실행]
npm.cmd install
node server.js
브라우저: http://localhost:3000

[다른 컴퓨터에서도 사용하려면]
이 폴더는 인터넷 서버 배포를 고려해 PORT 환경변수와 Docker를 지원합니다.
Docker 기반 호스팅 서비스에 이 폴더를 업로드하면 인터넷 주소를 받아 다른 컴퓨터와 휴대폰에서도 접속할 수 있습니다.

주의:
현재 버전은 data.json 파일에 공지/출석/채팅을 저장합니다.
호스팅 서비스를 실제 운영용으로 사용할 경우, 재시작 시 데이터가 유지되는 디스크(Volume) 또는 데이터베이스 연결을 설정하는 것이 좋습니다.
